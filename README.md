# JrMovies

Aplicativo front-end de catálogo e cadastramento de filmes em HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. O catálogo já vem com alguns filmes de demonstração.
4. Os filmes cadastrados/editados ficam salvos no `localStorage` do navegador.

## Estrutura
- `index.html` — telas e componentes
- `style.css` — design responsivo
- `script.js` — catálogo, filtros, CRUD e persistência local

## Observação
Esta versão é um protótipo funcional front-end. Para uso multiusuário real, login, banco de dados remoto e armazenamento de imagens, substitua o localStorage por uma API/backend e banco de dados.
